## Title

Loyalty Points Rewards Coupons Wallet Runtime

## Context

LYL-01..04 P0. Domain + schema stubs; expiry job is stub_acknowledged in outbox.

## Problem

No points earn/redeem/expire in production paths; customer wallet pages are stubs.

## Current State

point_rules/wallets/points_ledger/coupons schemas; loyalty use cases in-memory; PointsExpired job stub.

## Desired State

Configurable earn rules (default 100,000 IRR=1pt, 12-month expiry ADR-091), POS redeem, customer-visible wallet, expiry worker.

## Requirements

- LYL-01..04
- Events PointsEarned/Redeemed/Expired
- Per-store-membership wallet isolation

## Technical Design

Ledger-based wallet; scheduled job via outbox workers; POS redemption port; customer dashboard reads.

## Acceptance Criteria

- [ ] Sale awards points per rule
- [ ] Redeem decreases wallet and emits event
- [ ] Expiry job removes stale points

## Risks

- Double-earn on sale retries — need idempotency keys

## Dependencies

- ADR-093
- ADR-096
- ADR-109
