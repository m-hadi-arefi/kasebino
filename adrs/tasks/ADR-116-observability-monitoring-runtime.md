## Title

Structured Logging Metrics Tracing and Alerting Runtime

## Context

ADR-074/075 Accepted but not implemented; no OpenTelemetry, metrics, or alert rules.

## Problem

Production incidents cannot be diagnosed; NFR-05 unmet.

## Current State

No OTEL SDK; no Prometheus/Grafana/Sentry wiring; only console logs ad hoc.

## Desired State

Structured JSON logs, RED metrics, OTEL traces, error monitoring, alert runbooks for POS/OTP/outbox lag.

## Requirements

- NFR-05
- PII scrubbing phones
- Dashboards for DAM/error rate
- Alert on outbox lag and 5xx

## Technical Design

Add OTEL + logger; instrument route handlers and worker; export to chosen backend; document alerts (implements ADR-074/075).

- [ ] No phone numbers in plain logs
