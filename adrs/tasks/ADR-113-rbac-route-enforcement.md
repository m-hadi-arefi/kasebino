## Title

RBAC Authorization Enforcement at Routes and Use Cases

## Context

RBAC model + authorization helpers exist; middleware does not enforce roles; admin actions not gatekept in HTTP.

## Problem

Without enforcement, any future open route is unauthorized-access risk.

## Current State

src/rbac + identity authorization.ts tested; route handlers mostly absent; middleware audience header only.

## Desired State

Mandatory authZ checks on all /api/v1 merchant/admin routes; store-scoping; platform_admin for /admin APIs.

## Requirements

- Deny by default
- Audit admin actions
- Tenant isolation tests
- No trusting client merchantId alone

## Technical Design

Central requirePermission() in application layer; derive tenant from JWT not body; add negative tests.

## Acceptance Criteria

- [ ] Cross-tenant access returns 403
- [ ] Admin routes require platform_admin
- [ ] POS staff cannot call admin suspend

## Risks

- False denials breaking happy path
