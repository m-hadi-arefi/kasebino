## Title

Live Merchant and Admin Dashboard Analytics

## Context

AN-01..04 P0; ADM-01..03 P1. Dashboard pages and analytics contracts are stubs.

## Problem

No live overview/revenue/customer/retention charts; admin merchant management non-functional.

## Current State

Persian stubs under /dashboard and /admin/*; merchant-oltp-analytics + mgmt-dashboard-analytics in-memory; no HTTP.

## Desired State

OLTP-backed merchant AN widgets (60s TTL Redis); admin merchant list/activate/suspend audited; mgmt rollups from mongo when plane live.

## Requirements

- AN-01..04
- ADM-01
- Monthly Returning Customers
- Persian+Jalali widgets
- Audited admin actions

## Technical Design

Projection tables/counters updated from sale/order events; cache-aside 60s; admin APIs with platform_admin RBAC.

## Acceptance Criteria

- [ ] Dashboards reflect sales within TTL
- [ ] Retention metric computable
- [ ] Admin suspend blocks merchant access

## Risks

- Admin auth missing until ADR-095
