## Title

Catalog and Inventory Merchant Management

## Context

Catalog/inventory domain + schema stubs exist; no merchant product management UI or APIs.

## Problem

Without products/stock, POS and storefront cannot operate.

## Current State

Domain entities + in-memory repos; /dashboard stub only; components/domain/catalog is .gitkeep.

## Desired State

CRUD categories/products, barcode assign, stock adjust, InventoryChanged events, Persian search.

## Requirements

- Product create/update/soft-delete
- Barcode uniqueness per store
- Stock adjustments transactional
- Persian UTF-8 search considerations

## Technical Design

Merchant dashboard routes + APIs calling catalog/inventory modules; cache-aside invalidation on Product*/Inventory* events.

## Acceptance Criteria

- [ ] Merchant can manage store catalog end-to-end
- [ ] POS resolves new barcodes after create
- [ ] Soft-deleted products hidden from storefront

## Risks

- Multi-store catalog isolation bugs
