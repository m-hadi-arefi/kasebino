## Title

MinIO Object Storage Runtime for Receipts and Media

## Context

MinIO in Compose; client stub; ObjectStoragePort contracts; receipts referenced in POS but no SDK upload.

## Problem

Receipt PDFs/images and store branding assets cannot be stored.

## Current State

minio-storage contracts; no AWS SDK / minio package; ReceiptRef placeholders.

## Desired State

Working MinIO adapter; buckets for receipts/branding/QR; signed URL read policy; POS attaches ReceiptRef.

## Requirements

- No public unauthenticated write
- Signed GET for receipts
- Compose bootstrap bucket script
- Persian filenames safe UTF-8

## Technical Design

Add MinIO SDK; implement ObjectStoragePort; init buckets on compose; wire POS/store branding uploads.

## Acceptance Criteria

- [ ] Upload+download receipt round-trip via signed URL
- [ ] Branding image serves on storefront

## Risks

- Credential leakage in client
- Large object DoS

## Dependencies

- ADR-040
- ADR-096
- ADR-104
