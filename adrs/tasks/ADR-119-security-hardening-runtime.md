## Title

Security Headers CORS CSP and Penetration Smoke

## Context

ADR-076/077 contracts claim baseline; runtime headers/CORS/CSP deferred; auth bypass possible via x-merchant-id on realtime token.

## Problem

App is not production-hardened; open bypasses exist.

## Current State

Security architecture package; realtime token authorizer trusts x-merchant-id header; no security headers middleware.

## Desired State

Secure headers, strict CORS, CSRF strategy, remove header identity bypasses, pen-smoke checklist green.

## Requirements

- NFR-04
- Remove x-merchant-id trust
- Helmet-equivalent headers
- Pen smoke docs/ards ARD-020
- Regression: staging must not return `devOtp`; Console SMS must not be producible default
- Outbox max-retry path gets DLQ persistence (today empty catch comment-only)

## Technical Design

next.config headers; enforce session-only identity; security regression tests; threat model update; coordinate OTP policy fix with ADR-095.

## Acceptance Criteria

- [ ] Realtime token without session is 401
- [ ] Security headers present on HTML
- [ ] Pen smoke checklist archived
- [ ] Automated test fails if OTP appears in response when `NODE_ENV=staging` or production

## Risks

- Breaking local postman flows — document AUTH
