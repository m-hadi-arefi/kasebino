## Title

MongoDB Driver Event Warehouse Audit and Telemetry Runtime

## Context

Analytics plane contracts extensive; mongodb client stub; no mongodb npm driver; no live collections/indexes/TTL jobs.

## Problem

Audit/product analytics/clickstream/sessions/mgmt rollups cannot ingest.

## Current State

Packages for ADR-056..065 encode collection names and isolation; admin browse UIs stubs.

## Desired State

Official mongodb driver; warehouse consumer from outbox; audit/product/behavior/session writers; TTL indexes; failure isolation (never block POS).

## Requirements

- Mongo never OLTP SoT
- Ingest failure isolation ADR-065
- TTL per ADR-064
- Phone scrubbing in audit
- Persian labels in admin views

## Technical Design

Add mongodb driver; implement adapters; outbox consumer branch for warehouse; HTTP beacons for clickstream; admin APIs later via ADR-106.

## Acceptance Criteria

- [ ] Sale event mirrored to mos_events
- [ ] POS still succeeds if Mongo down
- [ ] TTL indexes present on retention collections

## Risks

- Dual-write consistency
- PII leakage to analytics

## Dependencies

- ADR-109
- ADR-056
- ADR-065
