## Title

Merchant Registration Onboarding and Multi-Store Setup UI

## Context

AUTH-06 merchant create-on-register; multi-store mandatory (ADR-091). No onboarding UI/API beyond domain stubs.

## Problem

New merchants cannot self-serve create account, first store, branding, or switch stores.

## Current State

Merchant/store domain + schemas; marketing landing page only; no register/onboarding routes.

## Desired State

Phone OTP register→create merchant→create first store (geo mandatory)→branding→staff invite basics; store switcher.

## Requirements

- AUTH-06
- Multi-store isolation
- Persian onboarding
- Activation gates POS/storefront

## Technical Design

Wizard under (merchant) group; APIs for merchant/store create; enforce activation policy before POS.

## Acceptance Criteria

- [ ] Fresh user becomes active merchant with one store
- [ ] Second store isolated inventory/membership
- [ ] Inactive merchant blocked from POS

## Risks

- Partial onboarding orphan records
