## Title

Payment Intents Webhooks and PSP Integration Path

## Context

Payment domain + sandbox gateway exist; ADR-084 PSP selection Proposed/not chosen; no HTTP routes.

## Problem

Online pickup orders cannot be paid; webhooks unwired.

## Current State

SandboxPaymentGateway + PaymentIntent use cases + in-memory repo; no /payments routes.

## Desired State

HTTP create-intent + webhook verify; sandbox for Kerman pilot; production PSP behind port once ADR-084 accepted.

## Requirements

- Idempotent webhooks
- HMAC/signature verify
- OrderPaid drives fulfillment
- Never trust client-paid flags
- Pilot free of transaction fees per ADR-091

## Technical Design

Route handlers for intents/webhooks; compose sandbox adapter; keep PaymentGateway port for provider swap.

## Acceptance Criteria

- [ ] Sandbox payment marks order Paid
- [ ] Replay webhook is idempotent
- [ ] Prod config rejects missing PSP secrets

## Risks

- Iran PSP quirks; webhook retries
