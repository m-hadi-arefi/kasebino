## Title

Customer SMS OTP and Membership Portal

## Context

CUST-01..03 P0. Customer OTP use cases + mock SMS exist; portal pages are stubs; JWT unwired.

## Problem

Customers cannot login or see points/history/rewards/receipts.

## Current State

/s/.../dashboard|orders|wallet shells; customer-identity module in-memory; consent noted in contracts.

## Desired State

Customer OTP login, membership-scoped portal with live wallet/history/orders/rewards.

## Requirements

- CUST-01..03
- Separate customer audience JWT
- Store-scoped membership
- Persian portal UX

## Technical Design

Wire customer OTP routes + Auth.js customer session; APIs read membership wallet/sales/orders; never cross-store bleed.

## Acceptance Criteria

- [ ] OTP login works in dev with returned code
- [ ] Portal shows live data for that store membership
- [ ] Logout clears session

## Risks

- Audience confusion with merchant JWT

- ADR-099
- ADR-032
