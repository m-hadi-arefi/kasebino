## Title

Store Location Maps Navigation and QR Print

## Context

LOC-01..02 and SF-12 / ADR-081 QR acquisition are mandatory store-first.

## Problem

No map/nav on about page; QR generation/print UI missing; geo may not be enforced on store create.

## Current State

qr-acquisition contracts; store schema stub with location fields; about page static Persian text.

## Desired State

Mandatory lat/lng+address on store; Neshan/Google-compatible nav links; printable PNG QR to storefront URL; analytics emit.

## Requirements

- LOC-01..02
- SF-12
- Merchant print UI
- Persian address fields

## Technical Design

Validate geo on store create/update; about page embeds map + nav deeplinks; QR lib generates PNG stored via MinIO optional.

## Acceptance Criteria

- [ ] Store cannot activate without geo
- [ ] About shows map/nav
- [ ] Merchant downloads printable QR

## Risks

- Map provider Iran availability

## Dependencies

- ADR-006
- ADR-081
- ADR-040
- ADR-094

## Estimated Complexity

**M**

## Iranian User Experience Requirements

- Persian copy + RTL for all new user-facing surfaces.
- Jalali dates and تومان formatting where money/time shown.
- Iranian phone (09xxxxxxxxx) validation for identity flows.
- Obey `docs/rules/iranian-first-development.md` and `docs/checklists/iranian-feature-checklist.md`.
