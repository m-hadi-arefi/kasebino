## Title

Live Storefront Catalog Pickup Checkout and Store Pages

## Context

SF-01..13 and ORD-10..12 are P0. Storefront routes are Persian shells with static CTA; no live catalog or order API.

## Problem

Customers cannot browse real products or place pickup orders.

## Current State

/s/[storeSlug] home/catalog/about + PWA manifest stubs; storefront-architecture contracts; no product APIs.

## Desired State

Dedicated branded storefront with live catalog, product detail, pickup-only checkout, about with map/nav, installable PWA.

## Requirements

- SF-01..04
- SF-10..13
- ORD-10..12
- No delivery UI
- revalidate/cache 600s storefront

## Technical Design

Server components fetch public DTOs; checkout creates Order Pending Payment → payment intent; branding from store settings; manifest dynamic per store.

## Acceptance Criteria

- [ ] QR/URL visitor browses and places pickup order
- [ ] Merchant sees new order in realtime/poll
- [ ] Lighthouse budgets tracked for storefront

## Risks

- Public data leakage of cost/stock internals
- PWA branding cache staleness

## Dependencies

- ADR-094
- ADR-097
- ADR-101
- ADR-086

**XL**

- Jalali dates and تومان formatting where money/time shown.
- Iranian phone (09xxxxxxxxx) validation for identity flows.
