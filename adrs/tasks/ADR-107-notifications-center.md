## Title

Notification Persistence SMS Outbox and In-App Center

## Context

ADR-090 module + templates + mock/console SMS; no HTTP list/read or UI center.

## Problem

Users cannot see in-app notifications; SMS only mocked.

## Current State

notifications schema stub; outbox handler; mock SMS channels; no center UI.

## Desired State

Persisted notifications, list/read APIs, merchant/customer Persian notification centers; SMS via port (prod provider ADR-083).

## Requirements

- In-app channel persist
- Idempotent outbox consumer
- Persian templates
- Read/unread

## Technical Design

Consume domain events → notification records; HTTP under /api/v1/notifications; UI drawers in dashboards.

## Acceptance Criteria

- [ ] Sale/order events create notifications
- [ ] List/read works with authZ
- [ ] Dev SMS console adapter logs Persian body

## Risks

- SMS cost without rate limits

- ADR-094
- ADR-083
- ADR-109
