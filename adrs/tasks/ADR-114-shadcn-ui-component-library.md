## Title

Generate shadcn/ui Primitives and Domain Components

## Context

components.json configured RTL new-york; src/components/ui and domain folders are empty .gitkeep only.

## Problem

No reusable accessibility-tested UI primitives; pages hardcode one-off markup.

## Current State

Tailwind tokens exist; no Button/Input/Dialog etc.; domain component dirs empty.

## Desired State

shadcn primitives installed; shared Persian form controls; POS/CRM/storefront composites under domain/.

## Requirements

- RTL-safe primitives
- Touch targets ≥44px
- Toman/phone inputs
- uiuxpromax before major screens

## Technical Design

npx shadcn add required set; wrap with MerchantOS tokens; build composites for phone keypad, toman display, status chips.

## Acceptance Criteria

- [ ] ui/ contains core primitives
- [ ] POS and storefront use shared inputs
- [ ] Axe/a11y smoke on forms

## Risks

- Design drift without uiuxpromax

## Dependencies

- ADR-019
- ADR-020
- ADR-021

**M**

## Iranian User Experience Requirements

- Persian copy + RTL for ops-facing UIs where merchant/admin visible.
