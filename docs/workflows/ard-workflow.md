# ARD Workflow

```
STATUS.md → select ready ARD → plan → (uiuxpromax?) → implement → validate → complete → next
```

### Creating a new ARD

1. Copy `docs/templates/ard-template.md`
2. Assign next ID
3. Map PRD requirement IDs
4. Declare dependencies
5. Add to README index + STATUS as `todo`
6. Do not start until scheduled by ard-to-code or human
