# Tech Stack Knowledge Base

Implementation guides for MerchantOS. Each guide defines purpose, conventions, anti-patterns, and usage.

**Persistence stack (mandatory):** PostgreSQL + **Drizzle ORM** (OLTP) + Redis cache-aside + DDD repository pattern.  
**Analytics plane (mandatory for PA-*):** **MongoDB** for warehouse/audit/telemetry (not OLTP SoT).
