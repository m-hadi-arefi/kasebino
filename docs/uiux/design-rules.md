# Design Rules

1. **uiuxpromax first** — mandatory before UI code.
2. **Mobile-first** — design 390px then enhance.
3. **POS exception** — favor large tap targets (≥44px), numeric keypad prominence, scanner feedback.
4. **One primary CTA** per view.
5. **No hero overlays** on marketing hero media.
6. **No dashboard-looking landing** — first viewport is one composition.
7. **Cards only for interaction containers**.
8. **Empty/error/loading states** required for every data view.
9. **RTL required (Iranian First)** — ship Persian RTL now with logical CSS properties; not a future polish item.
10. **Contrast** — WCAG AA minimum.
11. **Density modes** — POS compact; analytics comfortable.
12. **Don't invent features in UI** not in ARD/PRD.
