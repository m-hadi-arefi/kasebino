# Mobile-First

## Breakpoints

Mobile default → sm/md enhance → lg for analytics multi-column.

## POS on phone

- Sticky checkout bar
- Full-width keypad
- Scanner button always reachable thumb-zone
- Avoid hover-only actions

## Storefront

- Single column catalog
- Sticky add/order CTA

## Performance

- Limit heavy analytics charts on small screens (summary first)
- Compress images via Next.js image optimizer
