### Visual composition rules (user frontend + design-rules)

1. One composition in first viewport (not card grid).
2. Brand test: removing chrome still reads as کاسبینو.
3. No hero overlays (badges/stickers).
4. Cards only if interaction requires (FAQ uses details, not marketing card soup).
5. Screenshots: stylized product frames (POS / باشگاه / سفارش حضوری) — not stock collage.
