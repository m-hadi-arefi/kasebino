# ADR-151 Implementation Plan

## Summary
Centralize production fail-closed checks in composition boot to avoid dangerous "safe local defaults" leaking to production (e.g., Fake finance reader, inventory stubs, missing MinIO on worker). 

## Task Breakdown
- [ ] Add `assertProductionFinancePolicy` in `src/infrastructure/composition/production-guards.ts` to reject `fake` accounting provider in `production` environment.
- [ ] Update `docker-compose.yml` to include `MINIO_ENDPOINT`, `MINIO_ROOT_USER`, and `MINIO_ROOT_PASSWORD` for the `worker` service, and add `minio` to its `depends_on`.
- [ ] Update `docs/audit/` ops notes and document local degraded modes.
- [ ] Move `ADR-151` from `adrs/tasks/` to `adrs/done/` and update `STATUS.md`.
