# Plan — ADR-068 Environment and Secret Management

## Summary

Encode MerchantOS environment and secret management as an importable contract in `src/env-secrets/`: required env keys, `.env.example` only (never commit secrets), dedicated `AUTH_SECRET` separate from data-plane URLs, `DATABASE_URL` / `REDIS_URL` connection keys, fail-fast on missing required keys in production, and Persian edge-facing config-failure messages. Provide a zod-free `parseEnv` helper (no new Zod dependency this cycle; schema shape remains easy to migrate later). Enhance `.env.example` with auth + documented secret placeholders.
