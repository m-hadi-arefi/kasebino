# Plan — ADR-006 Store Domain — Location Branding Slug

Implement the **Store** operational/customer-facing aggregate under a merchant: globally unique `slug` for path storefront `/s/{slug}` (ADR-091), branding hooks, weekly hours, structured Iranian address + WGS84 lat/lng, status lifecycle, domain events `StoreCreated` / `StoreUpdated`, create + update branding/hours (and location) use cases with Persian error messages, in-memory repository, optional Drizzle `stores` schema stub.
