# Plan — ADR-034 Authorization RBAC Model

## Summary

Encode least-privilege RBAC at the application-service boundary: importable contract in `src/rbac/` (canonical roles, permission matrix, tenant/store-scoped checks, Persian deny messages, AuthZ deny metric notes) plus identity application helpers that authorize from JWT claims (ADR-033). Every sensitive query/mutation path must pass role + merchant (and store when required) scope checks.
