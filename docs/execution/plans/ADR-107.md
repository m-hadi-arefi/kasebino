## uiuxpromax brief (fa-IR / RTL / ~390px Android)

- **Persona:** صندوقدار کرمانی اعلان «سفارش جدید» را می‌بیند؛ مشتری اعلان «آماده تحویل» را در پنل فروشگاه می‌خواند و خوانده علامت می‌زند.
- **Context terms:** مغازه، صندوقدار، مشتری، سفارش، پیکاپ حضوری، اعلان
- **Composition:** `lang=fa`, `dir=rtl`; merchant max-width ~`max-w-lg`; customer portal same family tokens
- **Screens:**
  1. **مرکز اعلان‌ها (فروشنده)** — `/notifications` list unread/read + badge link from dashboard
  2. **اعلان‌های مشتری** — `/s/[storeSlug]/dashboard/notifications`
- **States (Persian):**
  - Loading: «در حال بارگذاری اعلان‌ها…»
  - Empty: «اعلانی نیست»
  - Error: «بارگذاری ناموفق بود. دوباره تلاش کنید.»
  - Mark read: «خوانده شد» / action «علامت به‌عنوان خوانده»
- **Component map:** `NotificationsCenterClient`, `notifications-providers`, FA copy in `src/modules/notifications/ui`; Query providers
- **A11y:** `aria-live` for load/error; unread badge `aria-label`; touch ≥44px
- **Assert:** `assertUiuxGate` in notifications UI tests

### Visual direction

Daylight merchant utility tokens — bordered interaction rows (not card-fest); no purple/cream clichés; clear unread vs read contrast without glow pills.
