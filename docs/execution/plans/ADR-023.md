# Plan — ADR-023 Store Customer PWA Architecture

## Summary

Encode MerchantOS **per-store customer PWA** at `src/store-customer-pwa/`: distinct audience from staff PWA (ADR-022), dynamic manifest path `/s/{storeSlug}/manifest.webmanifest`, `start_url` → storefront, Persian RTL install prompt copy, offline read-mostly catalog note, reserved install analytics events, customer JWT only. Add minimal manifest Route Handler + install banner on storefront home.
