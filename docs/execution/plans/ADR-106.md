## uiuxpromax brief (fa-IR / RTL / ~390px Android)

- **Persona:** صاحب مغازه در کرمان — بعد از ناهار داشبورد را نگاه می‌کند؛ ببیند امروز چقدر فروخته و چند مشتری برگشته. مدیر پلتفرم فروشندهٔ مشکل‌دار را تعلیق می‌کند.
- **Context terms:** مغازه، صندوق، مشتری، بازماندگی، تومان، تعلیق
- **Composition:** `lang=fa`, `dir=rtl`; merchant max-width column (existing dashboard tokens); admin wider table with scroll
- **Screens:**
  1. **داشبورد فروشگاه** — ویجت‌های نمای کلی / درآمد / مشتریان / بازماندگی (شمال‌ستاره)
  2. **فهرست فروشندگان ادمین** — وضعیت زنده + فعال‌سازی / تعلیق با تأیید
  3. **گزارش حسابرسی** — فهرست اقدامات با تاریخ شمسی
- **States (Persian):**
  - Loading: «در حال بارگذاری داشبورد…» / «در حال بارگذاری فروشندگان…»
  - Empty: «هنوز فروشی ثبت نشده» / «هنوز فروشنده‌ای ثبت نشده» / «هنوز رویداد حسابرسی نیست»
  - Error: «بارگذاری ناموفق بود. دوباره تلاش کنید.» / دسترسی رد شد فارسی
- **Component map:** `DashboardAnalyticsWidgets`, `AdminMerchantsClient`, `AdminAuditClient`; FA copy in `src/modules/analytics/ui` + `src/modules/admin/ui`; Query providers
- **A11y:** `aria-live` for load/error; confirm dialogs for suspend; touch ≥44px
- **Assert:** `assertUiuxGate` in analytics/admin UI tests
