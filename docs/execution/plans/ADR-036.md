# Plan — ADR-036 Event-Driven Architecture

## Summary

Encode MerchantOS event-driven architecture as an importable contract in `src/event-driven/`: past-tense domain events, canonical envelope, transactional outbox concept (same TX as aggregate write), at-least-once delivery with idempotent consumers, and fan-out consumers (cache invalidation, realtime/EMQX, analytics/warehouse, notifications) with analytics explicitly off the checkout critical path. Align with modular-monolith `OUTBOX_SPINE`. No UI / worker poll / EMQX wiring this cycle (ADR-035/038).
