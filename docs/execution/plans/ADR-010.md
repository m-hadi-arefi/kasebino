# Plan — ADR-010 Loyalty Architecture



## Summary



Implement Loyalty bounded context: **PointRule** (store-scoped earn rate + expiry config), **Wallet** per **StoreMembership**, append-only **PointsLedger**, earn-on-sale port usable by POS `LoyaltyEarnPort`, redeem with non-negative balance invariant, expiry policy **12 months after last earn** (ADR-091, merchant-configurable / disableable). Persian domain messages. In-memory repos + Drizzle stubs. No UI (customer portal → ARD-035; uiuxpromax N/A). Expire job use case callable; scheduler → ADR-035.
