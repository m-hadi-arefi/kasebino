# Plan — ADR-124 Realtime MQTT Client Subscriptions (Merchant)

## Summary

Wire authenticated merchant staff browsers to EMQX over MQTT.js WebSocket using short-lived tokens from `POST /api/v1/realtime/token`, with TanStack Query soft-refresh on orders/sales/inventory/notifications and **HTTP poll fallback** when MQTT is down or disabled (`NEXT_PUBLIC_MOS_MQTT_CLIENT=0`). Build on ADR-039 (`src/realtime-client`) + ADR-109 publish path; integrate pickup board (ADR-101), POS (ADR-096), and notifications badge/center (ADR-107).

**Status:** `in_progress` — **do not** move ADR to `done/` (operator request). **Do not** commit.

## Task breakdown

1. **Write this plan** before code; STATUS `in_progress`.
2. **Token hardening** (`token.ts` + route):
   - Require merchant session (already).
   - Resolve **active store** from cookie / optional body `storeId`; verify store `merchantId` match → else **403** Persian (cross-store denied).
   - Include `storeId` in token payload; retain merchant-scoped MQTT subscribe ACL (topic layout merchant-channel per ADR-038).
3. **mqtt.js browser transport** `createMqttJsRealtimeTransport` + env flag `isMqttClientEnabled()` (`NEXT_PUBLIC_MOS_MQTT_CLIENT`).
4. **Orchestrator enhancements** (`client.ts`):
   - `mqttEnabled: false` → immediate poll fallback (no connect attempt).
   - Filter envelopes by `storeId` when scope has store (cross-store ignore).
   - Invalidate **UI query prefixes** used by board/POS/notifications (`orders`, `pos`, `inventory`, `notifications`) in addition to scoped keys.
5. **`useRealtimeStoreChannel` hook** + Persian event toast helpers (`سفارش جدید`, etc.).
6. **Wire** orders board, POS register, notifications center — soft-refresh + connection status line.
7. **Docs:** `.env.example` + `docs/tech/emqx.md` WS path / client flag.
8. **Tests** + `DATABASE_URL=... npm run validate`.
9. Leave ADR in `adrs/tasks/`; no commit; no move to `done/`.

## Poll fallback intervals (documented)

| Mode | Interval | Trigger |
| --- | --- | --- |
| MQTT connected | Event-driven invalidate (+ board may keep soft poll) | Topic message |
| MQTT down / reconnecting | `DEFAULT_POLL_INTERVAL_MS` = **15_000** | Poll timer |
| MQTT disabled (`NEXT_PUBLIC_MOS_MQTT_CLIENT=0`) | **15_000** poll-only | Start in `poll_fallback` |
