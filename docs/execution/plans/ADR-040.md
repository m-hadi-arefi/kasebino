# Plan — ADR-040 File Storage MinIO Strategy

## Summary

Ship MinIO S3-compatible object storage as an importable contract in `src/minio-storage/`: private buckets for **receipts / media / qr**, `ObjectStoragePort` + in-memory adapter (presigned upload/download), env keys aligned with ADR-066 compose, object keys stored in PG (no DB BLOBs), `ReceiptRef` VO for POS receipts. Compose already provides `minio` — verify, do not re-implement. Real S3 SDK client deferred to a thin config stub (like ADR-051 Redis).
