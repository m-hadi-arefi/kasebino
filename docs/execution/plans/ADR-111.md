# Plan — ADR-111 MinIO Receipts and Asset Storage Runtime

## Summary

Land a live **AWS S3-compatible MinIO adapter** for `ObjectStoragePort`, store Persian RTL HTML receipts on CompleteSale (async retry via outbox when MinIO is down), issue **authZ-gated signed download URLs**, and enable **store logo/icon uploads** into the private `media` bucket with a storefront proxy for branding/PWA.

**Status:** `in_progress` — operator asked **not** to move ADR to `adrs/done/` this cycle.

## Fail policies

| Path | MinIO down |
| --- | --- |
| CompleteSale OLTP | **succeed** — receipt key null; outbox retries |
| Signed URL issue | **404/409** Persian if object missing; authZ first |
| Branding upload | **fail-closed** with FA validation errors |
| Outbox receipt consumer | throw → outbox retry / DLQ |
