### Brief (fa-IR / RTL / ~390px Android)

- **Persona:** صندوقدار مغازه محلی در کرمان — عجلهٔ صف ظهر؛ یک‌دستی اندروید.
- **Context terms:** مغازه، صندوقدار، مشتری
- **Composition:** `lang=fa`, `dir=rtl`; max-width mobile column; sticky checkout bar; thumb-zone اسکن/تسویه
- **Screens / steps:**
  1. **صندوق** — جستجو/بارکد + سبد + جمع تومان
  2. **دوربین بارکد** — overlay یا sheet؛ خطا فارسی اگر API نباشد
  3. **بازیابی بارکد ناموجود** — پیام + دکمه «جستجوی نام» + لینک ایجاد کالا (ADR-097 path `/products` stub message)
  4. **موبایل مشتری** — keypad 09… + اعلان رضایت کوتاه
  5. **تسویه** — نقد / کارت‌خوان / ترکیبی
  6. **رسید** — شماره مرجع، جمع تومان، تاریخ جلالی، فروش جدید
- **States (Persian):**
  - Loading: «در حال ثبت فروش…» / «در حال جستجو…»
  - Empty cart: «سبد خالی است — بارکد بزنید یا جستجو کنید»
  - Error: موجودی ناکافی، بارکد ناموجود، شماره نامعتبر، خطای شبکه
  - Success: «فروش ثبت شد» + مرجع رسید
- **Component map:** `PosRegister`, `ProductLookupBar`, `CameraBarcodeSheet`, `CartLines`, `PhoneKeypadCheckout`, `TenderPicker`, `SaleReceiptSummary`, providers (TanStack Query + Zustand cart)
- **A11y:** labels فارسی؛ focus روی ورودی جستجو؛ `aria-live` برای خطا/موفقیت؛ contrast توکن‌های موجود؛ targets ≥44px
- **Assert:** `assertUiuxGate` in unit test with this evidence
