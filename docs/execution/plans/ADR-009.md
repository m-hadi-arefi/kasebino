# Plan — ADR-009 POS and Sales Domain

Implement POS/Sales bounded context: **Cart** validation + **Sale** aggregate (lines, tender `cash|card_terminal|mixed` per ADR-091), **CompleteSale** UoW orchestrating validate → record tender → phone→membership upsert port → inventory decrement port → LoyaltyEarn stub → emit `SaleCompleted`.
