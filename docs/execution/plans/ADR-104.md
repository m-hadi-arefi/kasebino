## uiuxpromax gate (ADR-021) — BEFORE UI code

**Evidence:** `.cursor/skills/uiuxpromax-integration/SKILL.md` + `docs/uiux/*` present; external binary N/A → skill/docs fallback.

### Brief (fa-IR / RTL / ~390px Android)

- **Persona:** صاحب مغازه کرمان — آدرس و مختصات را وارد می‌کند، QR ویترین را چاپ می‌کند؛ مشتری با اسکن به ویترین می‌آید و مسیر مغازه را می‌بیند.
- **Context terms:** مغازه، آدرس، نقشه، مسیریابی، نشان، برچسب QR، ویترین
- **Composition:** Utility retail daylight tokens; one job per screen; no cards in hero; no purple/cream clichés; brand/`displayName` prominent on print sheet.
- **Screens:**
  1. **دربارهٔ مغازه** (`/s/[slug]/about`) — آدرس فارسی + تصویر نقشهٔ ثابت یا fallback متنی + دکمهٔ «مسیریابی» (نشان اولویت)
  2. **چاپ QR** (`/stores/[id]/qr`) — پیش‌نمایش موبایل + دستور چاپ A4؛ هدف URL با `?src=qr`؛ راهنمای برچسب ویترین
  3. **موقعیت فروشگاه** (`/stores/[id]/location`) — فرم آدرس فارسی + عرض/طول جغرافیایی با خطاهای فارسی
- **States (Persian):** loading نقشه / بدون ارائه‌دهنده نقشه («آدرس و مسیریابی در دسترس است») / مختصات نامعتبر / چاپ / خطا شبکه
- **Component map:** RSC about map section; client print actions (`window.print`); location form; copy under `src/modules/store/ui`; `assertUiuxGate` in module test
- **A11y:** `alt` فارسی برای نقشه/QR؛ ≥44px؛ `aria-live` برای خطا فرم

### Visual direction

Static map band edge-to-edge within column (not a floating card collage); Navigate as primary external link row preferring Neshan; print sheet centered QR + short Persian sticker CTA.
