# Plan — ADR-100 Live Storefront Catalog, Pickup Checkout, Store Pages

## Summary

Replace Persian shells under `/s/[storeSlug]` with a **live** branded storefront: public catalog + PDP, pickup-only checkout (no delivery UI), and store about pages bound to public ACL DTOs. Checkout (customer OTP session) creates a pickup order in `pending_payment`, creates a sandbox payment intent, and enqueues `OrderCreated` so merchant lifecycle / notifications can consume it.

**Status:** `in_progress` — do **not** move ADR to `done/` until operator confirms (this cycle leaves file in `adrs/tasks/`).

## uiuxpromax gate (ADR-021) — BEFORE UI code

**Evidence:** skill + `docs/uiux/*` present; external binary N/A → fallback via skill/docs.

### Brief (fa-IR / RTL / ~390px Android)

- **Persona:** مشتری محلی در کرمان — با QR روی شیشه وارد ویترین می‌شود، کالاها را می‌بیند، سفارش حضوری می‌دهد.
- **Context terms:** مغازه، ویترین، کالا، سبد، تحویل حضوری، پرداخت
- **Composition:** One column storefront; brand `displayName` hero-level on home; reuse daylight tokens + optional store `primaryColor` accent; no delivery chrome; no purple/cream clichés.
- **Screens:**
  1. **خانه ویترین** (`/s/[slug]`) — برند، «فقط تحویل حضوری»، لینک کاتالوگ/درباره/پنل، CTA سفارش
  2. **کاتالوگ** (`/s/[slug]/catalog`) — فهرست زنده + تومان + موجودی
  3. **جزئیات کالا** (`/s/[slug]/catalog/[productId]`) — نام، توضیح، قیمت تومان، افزودن به سبد
  4. **تسویه پیکاپ** (`/s/[slug]/checkout`) — سبد، فقط «تحویل حضوری»، بدون گزینه ارسال؛ نیاز ورود OTP؛ ثبت سفارش
  5. **درباره مغازه** (`/s/[slug]/about`) — آدرس/شهر/ساعات از پروفایل عمومی (نقشه → ADR-104)
- **States (Persian):** loading / empty («هنوز کالایی ثبت نشده») / OOS / 404 فارسی / unpaid timeout copy / network
- **Component map:** RSC pages + `CheckoutClient`; copy/format/api under `src/modules/storefront/ui`; `assertUiuxGate` in module test
- **A11y:** Persian labels; `aria-live`; ≥44px; fulfillment mode as plain text (not selectable delivery)

### Visual direction

Utility retail storefront — brand name first; soft list rows (not card grid for browsing); interaction cards only for cart lines / checkout submit.

## Tasks

1. **Plan + uiuxpromax brief** (this file) — before code
2. **Public read enhancements:** stock availability on storefront product DTOs; server loaders for profile/catalog/PDP; Persian inactive/unknown slug → notFound
3. **Checkout API:** `POST /api/v1/storefront/[slug]/orders` — customer session, rate-limit, price from catalog (not client trust), stock check, ensure membership (storefront join + consent), `createOrder` → `pending_payment`, `createIntent`, enqueue `OrderCreated` (+ payment intent event when created)
4. **UI:** live home / catalog / PDP / about; checkout cart (sessionStorage) + OTP gate; explicit «تحویل حضوری» only
5. **Wire router paths** in `app-router-structure` for PDP + checkout
6. **Tests + `npm run validate`** with `DATABASE_URL=postgres://merchantos:merchantos@localhost:5433/merchantos`
7. **STATUS / progress-log** notes; **do not** move ADR to `done/`
