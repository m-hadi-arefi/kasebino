# Plan — ADR-101 Pickup Order Lifecycle Merchant Board

## Summary

Ship a Persian RTL merchant **pickup-only** lifecycle board at `/orders` so staff can list open orders for the active store, advance `paid → preparing → ready_for_pickup → picked_up → completed`, and cancel / manually refund where policy allows. Consume existing `/api/v1/orders*` (ADR-094). Poll as mandatory refresh fallback (ADR-124 MQTT optional later). Ready-hold 24h signals from order timestamps (ADR-091); auto-cancel jobs remain ADR-109.

**Status:** `in_progress` — do **not** move ADR to `done/` (operator request this cycle).

### Brief (fa-IR / RTL / ~390px Android)

- **Persona:** فروشنده / صندوقدار مغازه محلی کرمان — سفارش‌های ویترین را می‌بیند، آماده می‌کند، به مشتری تحویل حضوری می‌دهد.
- **Context terms:** سفارش پیکاپ، آماده‌سازی، آماده تحویل، تحویل گرفت، لغو، بازپرداخت، تومان، مهلت ۲۴ ساعته
- **Composition:** One-column merchant board (mobile-first); status filter chips; vertical list grouped by status (kanban collapses to stacked columns on narrow). Soft interactive rows (cards only as action containers). Daylight tokens; no purple/cream clichés; no delivery chrome.
- **Screens:**
  1. **تابلوی سفارش‌ها** (`/orders`) — store selector, status filters, poll badge, order rows with line summary + تومان + Jalali time + primary next action + overflow cancel/refund
- **States (Persian):** loading («در حال بارگذاری سفارش‌ها…») / empty («سفارش بازی نیست») / network / invalid transition from API `messageFa` / ready-hold warning («کمتر از … تا پایان مهلت ۲۴ ساعته» / «مهلت آماده تحویل رو به پایان است»)
- **Component map:** RSC `page.tsx` + `OrdersProviders` + `OrdersBoardClient`; copy/api/format/actions under `src/modules/ordering/ui`; `assertUiuxGate` in module test
- **A11y:** Persian labels; `aria-live` for errors/success; status as text chips; ≥44px taps; disable double-submit while mutating

### Visual direction

Utility retail fulfillment board — status hierarchy first; one next-step CTA highlighted; secondary cancel/refund quieter; poll interval visible as subtle «به‌روزرسانی».
