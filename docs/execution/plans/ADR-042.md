# Plan — ADR-042 Drizzle ORM Exclusive Strategy

## Summary

Install and wire Drizzle as the **exclusive** SQL ORM for MerchantOS OLTP: deps (`drizzle-orm`, `drizzle-kit`, `postgres`), minimal `drizzle.config.ts` on `DATABASE_URL`, infrastructure client stub + empty centralized schema, and a `src/drizzle-orm-strategy/` contract forbidding Prisma/TypeORM/Sequelize/MikroORM/Objection and domain/UI Drizzle imports. No domain tables yet (ADR-043+). Migrations via Drizzle Kit deferred in detail to ADR-046 (scripts stubbed).
