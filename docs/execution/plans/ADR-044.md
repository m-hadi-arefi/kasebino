# Plan — ADR-044 Indexing Standards

## Summary

Encode MerchantOS OLTP indexing standards as an importable contract in `src/indexing-standards/`: explicit indexes (not ORM defaults alone); `merchant_id` leftmost on tenant composites; index every FK used in joins; unique business keys scoped per tenant with soft-delete-aware partial uniques (`WHERE deleted_at IS NULL`); covering indexes only when justified; no redundant left-prefix duplicates; document why per index; barcode/fuzzy Persian search detail deferred to ADR-050 (high-level UTF-8 / `fa` considerations only). Assert helpers + Vitest. Contract-only — no concrete domain index DDL.
