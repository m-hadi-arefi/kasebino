# Plan — ADR-051 Redis Architecture

## Summary

Encode MerchantOS Redis as an importable architecture contract in `src/redis-architecture/`: shared Redis for cache-aside and rate limiting across multi-instance deploys; **never** a source of truth (PostgreSQL remains OLTP SoT). Connect via `REDIS_URL` (documented in compose + `.env.example` from ADR-066). Key namespace / TTL detail deferred to ADR-053; cache-aside helpers to ADR-052; fail-open (cache) vs fail-closed (auth/OTP rate limits) notes deferred to ADR-055 with architecture pointers here. Optional thin Redis client stub under infrastructure (URL resolution only — no cache/rate-limit logic).
