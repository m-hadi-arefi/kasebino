# Plan — ADR-026 Data Fetching Strategy

## Summary

Encode MerchantOS data-fetching boundaries at `src/data-fetching/`: **RSC** for dashboards/marketing (where possible); **TanStack Query** for interactive POS/CRM client islands; **Route Handlers** for public/mobile JSON. Install `@tanstack/react-query`; provide `QueryClient` factory + provider stub; forbid ad-hoc `fetch` in `useEffect`; tune `staleTime` per surface; clear query cache on logout; preserve Persian Unicode and Persian RTL placeholders (no English flash).
