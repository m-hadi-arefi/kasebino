## Env flags

- `MOS_ALLOW_SANDBOX_PAYMENT_CONFIRM=1` — enable sandbox confirm HTTP
- Allowed only when `MOS_ENV` is `local` (or unset local) **or** `NODE_ENV=development`
- `MOS_PAYMENTS_WEBHOOK_SECRET` — optional override for sandbox HMAC (default documented secret)
