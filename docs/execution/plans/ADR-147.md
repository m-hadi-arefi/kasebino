## 1. Executive Summary

ADR-147 adds product image support to MerchantOS. While catalog CRUD operations (SKU, barcode, price, categories) are fully wired, products currently lack primary images, impacting storefront product detail pages and POS visual item selection. This task introduces product image upload, storage in MinIO, retrieval via signed/resolved URLs, and UI display across merchant admin, storefront, and POS.

---

## 2. Iranian First UX & Localization Compliance

- **Persian Microcopy:** All upload controls, progress states, delete confirmations, and empty states ship in Persian (`تصویر محصول`, `تغییر تصویر`, `حذف تصویر`, `تصویر انتخاب نشده است`).
- **RTL Support:** Image uploader components, file previews, and storefront/POS image cards use RTL logical alignment (`dir="rtl"`).
- **Iranian Mobile Devices:** Image size limits (e.g. max 5MB) and support for lightweight formats (JPEG, PNG, WebP) ensure high performance on mobile networks.

## 3. Scope & Technical Changes

### A. Database & Schema
- Update `products` table in `src/infrastructure/database/schema/catalog.ts` with:
  - `image_object_key`: text (nullable)
  - `image_updated_at`: timestamp with timezone (nullable)
- Generate migration `src/infrastructure/database/migrations/0008_catalog_product_images.sql`.

### B. Domain & Application
- Update `Product` aggregate model in `src/modules/catalog/domain/product.ts` to include `imageObjectKey?: string | null` and `imageUpdatedAt?: Date | null`.
- Add product image use cases in `src/modules/catalog/application/use-cases.ts`:
  - `uploadProductImage`: validates image mime type / size, uploads object to MinIO under `merchants/{merchantId}/products/{productId}/primary`, updates product record.
  - `deleteProductImage`: clears `imageObjectKey` on product record and removes object from MinIO.
- Update Drizzle repository mapping to persist and query `imageObjectKey` and `imageUpdatedAt`.

### C. API Surface & Composition
- Add HTTP API routes in `src/infrastructure/http/handlers/catalog.ts`:
  - `POST /api/v1/catalog/products/{id}/image` (multipart/form-data)
  - `DELETE /api/v1/catalog/products/{id}/image`
- Resolve product image URLs in GET endpoints using object storage URL resolver.

### D. Frontend & UI
- Add image upload component to merchant product form (`src/app/admin/products/product-form.tsx` or module UI).
- Update storefront product cards and PDP to display resolved product image or Persian placeholder.
- Update POS product list/search to display thumbnail image.

## 6. Risks & Mitigation

| Risk | Mitigation |
| --- | --- |
| Heavy image downloads on Iranian mobile networks | Validate image content types (JPEG, PNG, WebP) and enforce strict 5MB upload limit. |
| MinIO missing in local dev | Fallback gracefully to memory object storage or public placeholder URL when object storage is unconfigured. |
