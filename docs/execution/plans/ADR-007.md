# Plan — ADR-007 Customer Membership Model

## Summary

Implement first-class **StoreMembership** in the CRM bounded context: store-scoped by Iranian phone, customer identity separate from merchant auth, wallets deferred (loyalty ADR). Consent recording per ADR-091 (POS notice-continue vs digital checkbox). Upsert on POS phone capture; digital join requires explicit consent. In-memory repo + tests; Drizzle `store_memberships` stub with unique partial index. No UI / API routes this cycle.
