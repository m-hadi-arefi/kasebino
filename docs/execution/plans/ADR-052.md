# Plan — ADR-052 Cache-Aside Read Strategy

## Summary

Implement MerchantOS **cache-aside read helpers** in `src/cache-aside/`: get-or-load (HIT → return; MISS → loader/PostgreSQL → SET TTL → return), Redis never SoT, explicit null/negative caching policy, UTF-8 Persian payload safety, fail-open on cache errors (bypass to loader), optional in-process single-flight for stampede, thin `CacheAsideStorePort` + in-memory store for unit tests.
