# Plan — ADR-110 MongoDB Analytics, Audit, Clickstream, and Warehouse Runtime

## Summary

Land the official **`mongodb` driver** and analytics-plane adapters so warehouse / audit / clickstream / product / session streams write to Compose Mongo (`MONGODB_URL`). Wire outbox `mongodb_warehouse`, HTTP telemetry beacons, TTL index bootstrap (ADR-064), QR land + POS funnel instrumentation, and keep Mongo **never** OLTP SoT — POS/checkout succeed when Mongo is down (ADR-065).

**Status:** `in_progress` — operator asked **not** to move ADR to `adrs/done/` this cycle.

## Fail policies (documented)

| Path | Mongo down |
| --- | --- |
| CompleteSale / POS OLTP | **succeed** — warehouse via outbox retry; track fail-open |
| AuditPort `record` | **fail-open** (`queued_failed`) — never block admin/POS TX |
| Beacon HTTP | **202** best-effort queue or soft reject; never 5xx on Mongo outage for track class |
| Outbox warehouse consumer | throw → outbox retry / DLQ (at-least-once; off checkout path) |
