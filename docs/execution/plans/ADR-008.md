# Plan — ADR-008 Catalog and Inventory Domain

## Summary

Implement Catalog and Inventory bounded contexts: **Catalog** owns Product (SKU/barcode/category, merchant-scoped barcode uniqueness, IRR money); **Inventory** owns store-scoped StockItem (ADR-091). Domain events `ProductCreated` and `StockAdjusted` stubs. In-memory repos + tests; optional Drizzle schema stubs. Thin contracts in `src/catalog-domain/` and `src/inventory-domain/`. No UI / API routes this cycle.
