# Plan — ADR-025 State Management Strategy

## Summary

Encode MerchantOS client vs server state ownership at `src/state-management/`: **server state** belongs to the data-fetching library (TanStack Query — install/wiring in ADR-026); **ephemeral client UI** uses local React state / Context; **POS cart** is client state via Zustand (module path `src/modules/pos/ui/state`); **filters/deep links** use URL search params. **Redux is not mandated** (forbidden as default architecture). Clear client stores on logout. Preserve Unicode Persian in client payload caches; suspense/error placeholders Persian + RTL.
