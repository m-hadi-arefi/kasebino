# Plan — ADR-033 NextAuth JWT Strategy

## Summary

Encode NextAuth (Auth.js v5) **JWT session strategy** as MerchantOS identity infrastructure: importable decisions contract in `src/nextauth-jwt/` (stateless JWT, no server session store, claims `sub`/`merchantId`/`roles`/`tokenVersion`, secure cookies, short TTL) plus a minimal Auth.js config stub under `src/modules/identity/infrastructure/auth` that wires a Credentials/OTP bridge to ADR-031 verify without full UI or Route Handler pages. Uses existing `AUTH_SECRET` (ADR-068).
