# Plan — ADR-055 Rate Limiting Strategy

## Summary

Implement MerchantOS **Redis rate-limiting strategy** as an importable package in `src/rate-limiting/`: fixed-window counters for OTP (3/min) and auth (5/min), sliding-window for default (10 rps), admin (20 rps), and public storefront; thin Redis port + in-memory store for unit tests; fail-closed for OTP/auth when Redis errors; fail-open for distinguished public/cache-oriented read scopes; Persian 429 envelopes/`Retry-After`. No Next.js middleware wiring into live routes this cycle (consume API ready for Route Handlers / ADR-077).
