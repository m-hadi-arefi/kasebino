# Plan — ADR-037 Event Naming and Schema Governance

## Summary

Encode MerchantOS event naming and schema governance as an importable contract in `src/event-naming/`: past-tense PascalCase `eventType` (forbid command-like `CreateX` / `UpdateX` / `DeleteX` names), required `payloadVersion` with light in-repo schema registry rules, and an authoritative MVP event catalog drawn from domain modules plus `event-catalog.md` / store-first addendum. Catalog or payload changes require doc updates in the same PR/ARD. No UI / Confluent registry / CI docstring gate this cycle.
