# Plan — ADR-013 Admin Domain

## Summary

Implement the **Platform Admin** bounded context: `AdminUser` + enforcement actions (merchant activate/suspend), gated to `platform_admin` only, with every enforcement audited via **AuditPort** (in-memory stub wiring). Thin contract in `src/admin-domain/`. Extend Merchant aggregate with admin suspend / reactivate paths and `MerchantSuspended` event. No admin UI / HTTP routes this cycle (→ ADR-089 / ARD-018).
