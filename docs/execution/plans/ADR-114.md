## Task breakdown

1. Install shadcn CLI deps (`class-variance-authority`, `lucide-react`, Radix packages, `sonner`) via `npx shadcn@latest add … --yes`.
2. Ensure generated primitives live under `src/components/ui` and import `@/lib/utils` `cn`; remove empty `.gitkeep` where real files exist.
3. Tune primitives for MerchantOS: min tap on Button `min-h-11` (≥44px), logical padding classes where defaults use physical L/R.
4. Add composites under `src/components/composites/`:
   - `phone-keypad.tsx` — large digit pad; paste; Persian placeholder `۰۹۱۲۳۴۵۶۷۸۹`; uses `normalizeIranianMobile` / `toAsciiDigits`
   - `toman-display.tsx` — `formatTomanFa` display (+ optional input helper)
   - `status-chip.tsx` — Badge wrapper with FA status map
   - `jalali-date-text.tsx` — `Intl` fa-IR-u-ca-persian Asia/Tehran
5. Domain folder barrels (building-block re-exports) for `pos`, `crm`, `storefront` so folders are not `.gitkeep`-only.
6. Sample page `app/ui-kit/page.tsx` (Persian RTL kit smoke).
7. Unit smoke `src/components/index.test.ts` (node): filesystem presence of primitives; Persian defaults from helpers; RTL markers on demo page / composites; no `.gitkeep`-only blocker for ui/composites/key domains.
8. Update `adrs/STATUS.md` tasks note to **in_progress** (do **not** move ADR to `done/`; do **not** commit).
9. `DATABASE_URL=postgres://merchantos:merchantos@localhost:5433/merchantos npm run validate`.
