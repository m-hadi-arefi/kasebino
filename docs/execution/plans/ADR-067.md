# Plan — ADR-067 Containerization Standards

## Summary

Ship production-grade MerchantOS containerization: multi-stage Next.js `Dockerfile` (standalone output, non-root runtime, healthcheck, no baked secrets), `.dockerignore`, and an importable contract in `src/containerization/` encoding non-root, health/ready targets, and 12-factor process rules. Wire Next `output: "standalone"`. Minimal `GET /api/health` liveness so image `HEALTHCHECK` is real. Local Compose `app` profile remains bind-mount/dev (ADR-066); prod image is the Dockerfile artifact.
