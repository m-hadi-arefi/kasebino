# Plan — ADR-109 Outbox Worker, Scheduled Jobs, and Live EMQX Publishing

## Summary

Land a **long-running outbox worker** that polls PostgreSQL `outbox_events`, fan-outs to EMQX (mqtt.js) + cache invalidation + notifications (+ warehouse process-local until ADR-110), persists **DLQ** after max retries, and runs **pickup unpaid (30m) / ready-hold (24h) / loyalty expiry** scheduled jobs with Persian staff-facing timeout copy. Compose gains an optional `worker` service depending on Postgres + EMQX.

**Status:** `in_progress` — operator asked **not** to move ADR to `adrs/done/` this cycle.
