## 1. Executive Summary

ADR-153 introduces merchant subscription plans, fee configuration rules, credit balances, and feature flag evaluation into MerchantOS. This foundation supports gating premium capabilities (such as advanced analytics or high-volume SMS credit top-ups) while keeping all fee rules inactive (0%) during the Phase 1 Kerman pilot phase.

## 3. Scope & Technical Changes

### A. Database & Schema
- Update `src/infrastructure/database/schema/merchants.ts`:
  - Add `merchant_subscriptions` table (`id`, `merchantId`, `planCode`, `feeBps`, `featuresJson`, `startsAt`, `expiresAt`, `createdAt`, `updatedAt`).
  - Add `merchant_credit_ledger` table (`id`, `merchantId`, `amountMinor`, `reason`, `referenceId`, `createdAt`).
- Generate Drizzle migration `src/infrastructure/database/migrations/0010_merchant_subscriptions_credits.sql`.

### B. Domain & Application
- Create feature flag evaluator service under `src/modules/merchant/application/feature-flags.ts`:
  - `evaluateFeatureFlag(merchantId: string, flagKey: string): boolean`.
- Implement subscription and credit repository ports and adapters.
- Implement subscription management use cases (`getMerchantSubscription`, `assignMerchantPlan`, `getCreditBalance`, `topupCredits`).

### C. HTTP API Surface & DTOs
- `GET /api/v1/merchants/subscription` — returns active plan, feature flags, and credit balance in تومان DTO.
- `PATCH /api/v1/admin/merchants/{id}/plan` — platform admin endpoint to update merchant plan & fee rules.
