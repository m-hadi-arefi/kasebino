### Brief (fa-IR / RTL / ~390px Android)

- **Persona:** صاحب/پرسنل مغازه محلی در کرمان — بعد از شیفت صندوق، افزودن چند کالای جدید و تنظیم موجودی قفسه.
- **Context terms:** مغازه، صندوقدار، مشتری
- **Composition:** `lang=fa`, `dir=rtl`; max-width mobile column (like dashboard/POS); sticky primary CTA for ذخیره / تعدیل موجودی
- **Screens:**
  1. **فهرست کالاها** (`/products`) — جستجوی فارسی نام، لیست فعال، لینک افزودن، ورود به جزئیات
  2. **فرم کالا** (ایجاد / ویرایش) — نام فارسی، بارکد، SKU، قیمت تومان، دسته اختیاری، توضیحات؛ حذف نرم
  3. **دسته‌ها** (بخش همان صفحه یا فرم کوتاه) — ایجاد/ویرایش نام؛ حذف نرم
  4. **موجودی** (`/inventory`) — انتخاب فروشگاه فعال، لیست موجودی per product، دلتای تعدیل (±) با دلیل اختیاری
- **States (Persian):**
  - Loading: «در حال بارگذاری کالاها…» / «در حال ذخیره…»
  - Empty: «هنوز کالایی ثبت نشده — اولین کالا را اضافه کنید»
  - Error: بارکد تکراری، SKU تکراری، موجودی منفی، خطای شبکه — پیام‌های فارسی دامنه
  - Success: «کالا ذخیره شد» / «موجودی به‌روز شد»
- **Component map:** `ProductsPageClient`, `ProductForm`, `CategoryInlineForm`, `InventoryPageClient`, `StockAdjustRow`, shared FA copy module, reuse merchant Query provider pattern from POS
- **A11y:** labels فارسی؛ `aria-live` برای خطا/موفقیت؛ focus به نام کالا روی فرم؛ targets ≥44px
- **Assert:** `assertUiuxGate` in `src/modules/catalog/ui/index.test.ts`
