# Plan — ADR-011 Pickup Order Architecture

## Summary

Implement Ordering bounded context: **Order** aggregate with **pickup-only** fulfillment lifecycle (`pending_payment` → `paid` → `preparing` → `ready_for_pickup` → `picked_up` → `completed` | `cancelled` | `refunded`). Timers from ADR-091 (`PICKUP_TIMER_POLICY`: unpaid 30m → auto-cancel; ready hold 24h → staff cancel, no silent refund). Persian status labels. Inventory reserve + payment confirmation ports as stubs (ADR-012 / ARD-034 later). No delivery states, no shipping tables, no UI (uiuxpromax N/A). In-memory repo + Drizzle stubs.
