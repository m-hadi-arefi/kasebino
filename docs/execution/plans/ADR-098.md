### Brief (fa-IR / RTL / ~390px Android)

- **Persona:** صاحب مغازه محلی در کرمان — بعد از شیفت، شماره مشتری‌های صندوق را می‌بیند و مشتری‌های بازمانده را فیلتر می‌کند.
- **Context terms:** مغازه، صندوقدار، مشتری، عضویت
- **Composition:** `lang=fa`, `dir=rtl`; max-width mobile column (like catalog/dashboard); sticky store selector + segment chips
- **Screens:**
  1. **فهرست مشتریان** (`/customers`) — انتخاب فروشگاه، فیلتر بخش (همه / جدید / بازگشتی / بازمانده)، جستجوی شماره، لینک پروفایل
  2. **پروفایل مشتری** (`/customers/[id]`) — هویت (شماره ملی ایران)، منبع عضویت، آمار تعامل، تاریخچه خرید
  3. **ویجت مشتریان داشبورد** — تعداد عضویت فعال + خلاصه بخش‌ها با لینک به `/customers`
- **States (Persian):**
  - Loading: «در حال بارگذاری مشتریان…» / «در حال بارگذاری تاریخچه…»
  - Empty: «هنوز مشتری‌ای ثبت نشده — از صندوق شماره بگیرید»
  - Empty segment: «در این بخش مشتری‌ای نیست»
  - Error: دسترسی، فروشگاه نامعتبر، شبکه — پیام فارسی
- **Component map:** `CustomersListClient`, `CustomerProfileClient`, FA copy + format helpers in `src/modules/crm/ui`, reuse merchant Query provider pattern from catalog
- **A11y:** labels فارسی؛ `aria-live` برای خطا/بارگذاری؛ segment chips با `aria-pressed`; targets ≥44px
- **Assert:** `assertUiuxGate` in `src/modules/crm/ui/index.test.ts`

## Segment definitions (document in code + tests)

Computed **on read** from active memberships + completed sales (status=`completed`, not soft-deleted). No rebuild button / projection table.

Exclusive assignment (first match wins):

1. **lapsed (`بازمانده`):** ≥1 completed sale AND last `completedAt` older than **60** calendar days (`Asia/Tehran`).
2. **returning (`بازگشتی`):** completed sale count ≥ **2** AND not lapsed.
3. **new (`جدید`):** otherwise (0–1 completed sales, or joined without qualifying as returning/lapsed).

Constants exported as `CRM_SEGMENT_POLICY` for tests.
