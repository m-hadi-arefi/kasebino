### Brief (fa-IR / RTL / ~390px Android)

- **Persona:** مشتری محلی در کرمان — با QR وارد ویترین همان مغازه می‌شود، با پیامک وارد پنل می‌شود، امتیاز و سفارش‌ها را می‌بیند.
- **Context terms:** مغازه، مشتری، عضویت، پیامک، کد تأیید، امتیاز، سفارش حضوری، رسید
- **Composition:** One-column portal under `/s/[slug]/dashboard`; brand via store slug/name in chrome; daylight tokens; utility bordered rows (interaction containers only); no merchant/staff chrome; no purple/cream clichés.
- **Screens:**
  1. **ورود OTP** (`/s/[slug]/login`) — phone + **explicit consent checkbox** before send; OTP step; Persian errors; optional `devOtp` only when allow-flag
  2. **پنل من** (`…/dashboard`) — profile summary, quick nav (wallet/orders/rewards/receipts), logout
  3. **کیف امتیاز** (`…/wallet`) — live balance + ledger (ADR-099 path)
  4. **سفارش‌ها** (`…/orders`) — live pickup orders for this membership
  5. **جایزه‌ها** (`…/rewards`) — honest empty («هنوز جایزه‌ای فعال نیست»)
  6. **رسیدها** (`…/receipts`) — POS sales list; signed MinIO URL deferred (ADR-111) — empty download until then
- **States (Persian):** loading «در حال بارگذاری…» / empty orders·wallet·rewards·receipts / auth redirect / network / cross-store forbidden
- **Component map:** enhance `CustomerOtpLoginForm`; portal shell + clients under dashboard; copy in `src/customer-dashboard` + thin UI helpers; `assertUiuxGate` / dashboard gate evidence updated for ADR-103 brief path
- **A11y:** Persian labels; consent checkbox associated text; `aria-live` status; ≥44px primary actions; logout clear

## Test matrix

- OTP request without consent → 400 `CONSENT_REQUIRED`
- OTP verify without consent → blocked
- Dev OTP returned when `NODE_ENV=development` or `MOS_RETURN_DEV_OTP=1`; never in staging/production without flag
- Successful verify → customer JWT audience + membership for that store
- Portal `me` / orders / wallet scoped to membership store; session store A cannot read store B (403)
- Logout clears session (subsequent portal GET → 401)
- Honest empty rewards/receipts download
