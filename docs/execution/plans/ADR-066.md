# Plan — ADR-066 Docker and Compose Local Parity

## Summary

Ship local/staging-parity Docker Compose for MerchantOS data + app planes: postgres (OLTP), redis, emqx, minio, mongo (analytics/audit/telemetry only), and optional-profile `app`. Encode expectations as a testable contract in `src/docker-compose-parity/`. No OLTP schemas (ADR-041), no Mongo warehouse schemas (ADR-056+), no delivery.
