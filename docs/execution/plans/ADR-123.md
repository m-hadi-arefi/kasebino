## How to add a new module binding (doc target)

1. Implement domain port + Drizzle adapter; register in `createProductionRepositoriesFromDb`.
2. Add use-case factory wiring inside `createApiContext` (test-injectable options).
3. Export via `ApiContext`; consume from HTTP handler with `getApiContext()`.
4. Worker-only consumers: bind from `ProductionRepositories` in `createOutboxWorkerRuntime` (same factory).
